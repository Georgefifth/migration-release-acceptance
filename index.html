Keep the scope visible

GO_WITHIN_SCOPE applies only to the declared synthetic workflow. Sequential tests do not establish concurrent behavior, lock duration, large-backfill performance or production safety.

A human controls merge and deployment. The example synchronization SQL is fixture-specific, not a universal migration recipe.

Use your application's own checks

  1. Install the reviewed wheel in your test environment.

    The package is not on PyPI. Use the build artifact and installation guide.

  2. Map a synthetic business operation.

    Provide reviewed startup, authentication, HTTP/ID mapping, baseline data and candidate SQL. Read the adapter contract.

  3. Preflight, then run on a disposable database.

    Preflight imports trusted configuration, but does not start an app or access a database. Execution requires your disposable DB settings.

    migration-accept --integration project_acceptance:integration --candidate title-storage --check
migration-accept --integration project_acceptance:integration --candidate title-storage --output reports/title-storage

Application integration still needs reviewed code. Independent setup savings and customer adoption are unverified.
